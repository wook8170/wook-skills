# work-status — 현재 상태 확인 (읽기 전용)

아무것도 고치지 않는다. 커밋·push·프로세스 종료·서버 재기동을 하지 않는다.

1. 수집 스크립트를 저장소 루트에서 실행한다. `<스킬 폴더>` 는 이 스킬을 불러올 때 표시되는 기본 디렉터리다.
   `bash <스킬 폴더>/collect.sh <저장소 경로>` (기본 현재 디렉터리)
   - 스크립트는 프로젝트 설정 파일에서 `gate-stamp`(게이트 통과 표식 파일 이름, git 공용 디렉터리 안. 기본 `gate-pass`)와 `ports`(확인할 서버 포트를 공백으로 구분. 기본 `3000 4173 5173 5174 8000 8080`)를 읽는다. 설정 줄 형식은 `- \`gate-stamp\`: \`<이름>\`` 이다.
2. 이 세션이 띄운 서브에이전트가 있으면 `ListAgents` 로 돌고 있는 것을 확인한다(이름·맡은 일). 보고 파일(`<scratchpad>/reports/*.md`)이 있으면 최신 것의 첫 줄만 읽는다.
3. 사용자에게 한국어로 짧게 요약한다. 순서:
   - **한 줄 요지**(지금 무엇이 진행 중이고 막힌 게 있는지)
   - **진행 중**: 서브에이전트·백그라운드 작업(무엇을, 어디서, 얼마나 됐는지)
   - **브랜치·워크트리**: main 대비 앞/뒤, 미커밋, 머지 대기·조건
   - **서버**: 포트·실행 위치(다른 워크트리 코드를 서빙하면 표시)
   - **주의**: 부하가 높음(부하 평균 > 20), 오래된 워크트리, 꺼진 서버, 게이트 표식 없음, 미커밋 핸드오프 등
   - **확인 대기**: progress.md 의 오너 결정 사항
   표는 꼭 필요한 곳에만 쓰고, 원격 사용자가 보므로 로컬 경로는 짧게 줄인다.
