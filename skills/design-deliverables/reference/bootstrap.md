# 산출물 세트가 없는 저장소에서 시작하기

## 1. 최소 구성(첫 변경)

```
docs/deliverables/design/
  README.md            # 폴더 구조 · 원고 규칙 · 재생성 명령 · 현행화 시점(사람이 읽는 운영 안내)
  catalog.json         # { categories: [...], books: [{ id, category, title }] }
  <ID>-01-<slug>/book.json + 01-개요.md
scripts/deliverables/
  build-index.mjs      # 대장 · 권 메타 · 장 → INDEX.md · index.json(+ --check)
  check.mjs            # 형식 · 장 구조 · 근거 경로 · 어미 · 생성 장 해시 · 색인 드리프트
  gen-chapters.mjs     # book.json 의 generator 를 보고 *.gen.md 를 만든다(처음엔 생성기 1개)
  deliverables-check.mjs  # ① 생성 장 재생성 비교 ④ check.mjs 를 한 명령으로
```

- 첫 변경에서는 권 1~3개, 생성기 1개(가장 쉬운 전수 목록 — 라우트 · API · 테이블 중 하나), 검사 2단계(재생성 비교 · 정합)만 세운다. 원천 데이터 비교와 추적 래칫은 추적표 권을 만들 때 더한다.
- 검사 명령을 저장소 관문(`gate` · CI)에 넣는다. 관문에 없는 검사는 곧 지켜지지 않는다.
- 조판은 프로젝트에 조판기가 있으면 그것을 쓰고, 없으면 `pdf-typeset` 스킬의 도우미(`print-pdf.mjs` · `pdf-nav.mjs` · `check-pdf.py`)로 시작한다.
- 문서 규칙(`writing-rules.md` 점검표)을 README 원고 규칙 절에 옮겨 적고, 금지 표현은 검사기 목록으로 강제한다.

## 2. 권을 만드는 우선순위

추적의 뼈대가 되는 권부터 만든다. 뒤 권들이 앞 권의 ID 를 인용하기 때문이다.

1. **요구사항 정의서** — 요구사항 ID 체계와 원천(기능 원장 CSV + 비기능 원천 JSON). 이후 모든 권이 이 ID 를 쓴다.
2. **기능 명세서 · 프로그램 목록** — 기능 원장과 코드에서 생성.
3. **화면 설계서의 화면 ID 대장** — 라우터에서 뽑는다. 스토리보드는 나중이어도 ID 는 먼저 고정한다.
4. **API 규격서 · 데이터 설계서(테이블 정의 · ERD)** — OpenAPI · 마이그레이션에서 생성. 생성 비율이 높아 적은 수고로 분량이 나온다.
5. **권한 매트릭스** — 서버 라우트 × 역할. 거부 시험과 같은 원천을 쓴다.
6. **시험 계획서 · 시험 케이스 명세서 · 추적표** — 요구사항 → 화면 → 시험 연결과 끊김 래칫.
7. **아키텍처 · 보안 · 배포 운영 설계서** — 사람이 쓰는 비중이 큰 권. 다이어그램 원본(D2 · Mermaid)을 텍스트로 둔다.
8. 나머지(DB 표준 · CRUD · 유즈케이스 · 클래스 · 배치 · 메시지 코드 · 오픈소스 · 접근성 · 정적 분석 · 형상 관리 · 이행 · 장애 대응 · 개인정보 흐름 · 교육 · UI 가이드 · 코딩 컨벤션 · 디자인 시스템) — 사업 요구에 따라 고른다.

GS 인증 · 감리 제출이 목표면 시험 계획 · 결과 · 케이스와 추적표를 앞당긴다.

## 3. 기준 저장소의 스크립트를 가져다 쓸 때 바꿀 곳

기준 저장소의 스크립트에는 그 저장소의 경로 · 이름이 상수로 들어 있다. 복사한 뒤 아래를 먼저 바꾼다.

| 파일 | 바꿀 것 |
|---|---|
| `build-index.mjs` | `DD_REL`(산출물 폴더) · `SPEC_DIR_REL`(책 명세 폴더) · `VOLUME_MIN`(분량 하한) · 그림 줄 정규식 |
| `check.mjs` | 출력 자리(`outDir`) 강제 값 · 표지 배포 등급 문구 · 어미 · 금지 표현 목록 출처 |
| `gen-chapters.mjs` | 생성기별 원천 경로(OpenAPI · 라우터 · 마이그레이션 · 기능 원장 CSV · 도구 · CLI 데이터) |
| `gen/doc-text.mjs` | 표기 변환 규칙(제품 용어 사전에 맞춘다) |
| `build-xlsx.py` · `xlsx/<권 ID>.py` | 권 ID 접두 · 출력 폴더 · 생성기 파일 이름 규칙 |
| `trace-ratchet.mjs` | 추적 데이터 경로 · 끊김 종류 |
| `screen_items.py` | 앱 소스 루트(`RS` · `SV`) · 공통 UI 폴더 제외 목록 · 대장 · 권한 원장 경로 · `SHARED_MAX` · 화면별 예외(`DROP_KIND_FOR`) |
| `ds-specimen/*` | 토큰 CSS 경로 · 공용 클래스 접두 · 시험 스택 포트 · 시드 계정 환경 변수 |
| `build-combined.mjs` · `build-xlsx-combined.py` | 권 PDF · 엑셀 경로, 시트 이름 접두(`DD<nn>-`) |
| 조판 책 명세(`_dd.mjs` 계열) | 표지 문구 · 색 · 배포 등급 · 결재 칸 · 가로 표 기준(역할 열 목록) |

가져온 뒤에는 결과에 날짜 · 시각이 들어가지 않는지(재생성 비교 성립), 생성기가 같은 입력에서 같은 결과를 내는지 두 번 돌려 확인한다. 스크립트마다 붙어 있던 단위 시험도 함께 가져와 경로를 맞춘다.
